# Навык: brain-search

Этот навык используется для быстрого нахождения нужной информации в базе знаний Obsidian.

## Процесс поиска

### Шаг 1: Формирование поискового запроса
Сформируйте поисковый запрос на основе вопроса пользователя или недостающего контекста.
Вы можете искать:
1. **Ключевые слова:** Например, `aiogram callback` или `n8n webhook`.
2. **Теги:** Например, `tags: project/arbat` или `#project/arbat`.
3. **Метаданные (Frontmatter):** Например, `type: decision` или `status: evergreen`.

### Шаг 2: Выполнение поиска через Grep
Используйте инструмент `grep_search` для поиска по директории Obsidian (`D:\Яндекс Диск\YandexDisk\выапорпоапраппаапр\Новая папка\Антигравити и Обсидиан\Obsidian`).

Для более эффективного поиска:
- Установите `CaseInsensitive: true`.
- Используйте `IsRegex: true` для поиска по полям Frontmatter. Например, регулярное выражение `type:\s*decision` для поиска всех архитектурных решений.
- Чтобы найти заметку по тегу, ищите строку `- project/имя-проекта` или `- topic/имя-темы` в блоке Frontmatter.

### Шаг 3: Фильтрация и ранжирование результатов
1. Ограничьте вывод до **10 наиболее релевантных результатов**.
2. Отсортируйте их по качеству соответствия:
   - Сначала точные совпадения в заголовке заметки (`title:`).
   - Затем совпадения в поле `summary` или `tags`.
   - Затем совпадения в теле текста.
3. Форматируйте вывод для пользователя в виде таблицы или списка со ссылками на найденные файлы.

Пример структуры вывода:
* **[Название заметки](file:///путь_к_файлу)** (Тип: `decision`, Статус: `evergreen`) — *Краткое резюме заметки.*
