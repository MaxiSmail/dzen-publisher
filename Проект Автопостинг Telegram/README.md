# 🤖 Автономный Telegram-автопостинг (ИИ + RSS)

Автоматическая система автопостинга новостей об Искусственном Интеллекте и Технологиях в Telegram-канал.

## 🚀 Описание работы
1. **Парсинг:** Мониторинг RSS-лент (Habr, TechCrunch, VentureBeat).
2. **ИИ-Редактор:** Gemini API адаптирует новость, переводит её на русский язык, делает верстку с HTML-тегами и эмодзи, генерирует промпт для картинки.
3. **Обложка:** Pollinations AI бесплатно создает уникальное изображение 1280x720.
4. **Публикация:** Telegram Bot API публикует пост в канал и заносит ссылку в историю (`posted_history.json`).

## 🛠 Запуск
1. Установите зависимости:
```bash
pip install -r scripts/requirements.txt
```
2. Проверьте настройки ключей в `scripts/.env`.
3. Запустите главный скрипт:
```bash
python scripts/main.py
```
