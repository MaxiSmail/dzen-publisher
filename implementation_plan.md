# Интеграция системы «БМК Управление» и модернизация UI веб-платформы

Данный план включает разработку интерактивного модуля управления объектами и заявками («БМК Управление»), внедрение анимаций Framer Motion, калькулятора стоимости инженерных систем и улучшение UX приложения.

## User Review Required

> [!NOTE]
> **Новый функционал панели управления:**
> В шапку сайта (Navbar) добавляется кнопка доступа к платформе «БМК Управление», которая открывает интерактивный дашборд контроля проектов (этапы проектирования, монтажа, СКУД, АСУ ТП, статус документации).
