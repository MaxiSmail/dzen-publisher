# Project Booster Skill 🚀

Этот навык выполяет мгновенное разворачивание нового проекта при вызове команды `/new-project`.

## 💻 Использование

Когда пользователь говорит `/new-project [Имя_Проекта] [Категория] [Стек]` или просит *«Создай новый проект [Имя]»*, агент автоматически выполняет:

```bash
node .agents/scripts/create_new_project.js --name "[Имя_Проекта]" --category "[Категория]" --stack "[Стек]"
```

## 📋 Что создается за один шаг:
1. Папка в `Antigravity/Проект [Имя_Проекта]/`.
2. Файлы `.gitignore`, `.env.example` и начальный `README.md`.
3. Карточка проекта `Obsidian/Projects/[Имя_Проекта].md` со стандартизированным Frontmatter.
4. Проставление всех вики-ссылок в `База знаний.md` и дашборде `Мои Задачи.md`.
