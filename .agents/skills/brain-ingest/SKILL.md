# Навык: brain-ingest

Этот навык используется для импорта внешних знаний (статей, документации, чужого кода, книг) в вашу базу знаний Obsidian.

## Процесс импорта

### Шаг 1: Получение источника
Входными данными могут быть:
1. URL-адрес веб-страницы (используйте `read_url_content` для извлечения текста).
2. Путь к файлу на диске (используйте `view_file` для чтения содержимого).
3. Произвольный текст, отправленный пользователем.

### Шаг 2: Извлечение ключевых идей
Не копируйте текст источника целиком. Проанализируйте его и выделите:
- Ключевые термины и концепции.
- Практические рекомендации (Actionable Insights).
- Примеры кода или конфигураций.
- Логические блоки информации.

### Шаг 3: Создание атомарных заметок (Atomic Notes)
Для каждого обособленного концепта или идеи создайте **отдельную (атомарную) заметку**:
1. Выберите подходящий тип (например, `insight` для концепций, `decision` для проектных решений).
2. Сформируйте короткое информативное имя файла в стиле kebab-case.
3. Разместите файл в соответствующей папке (например, `Obsidian/Projects/{project-name}/` или `Obsidian/ADR/`).
4. Заполните Frontmatter, указав источник в поле `source` (URL или путь к файлу-источнику).

### Шаг 4: Связывание и проверка дубликатов
- Выполните поиск через `grep_search`, чтобы убедиться, что концепция еще не описана в базе знаний.
- Если концепция уже описана, дополните существующую заметку, обновив поле `updated`.
- Добавьте кросс-ссылки на смежные заметки.
