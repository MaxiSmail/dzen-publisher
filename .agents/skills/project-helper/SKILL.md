# Project Helper Skill 🚀

Этот навык обучает агента управлять кодовой базой и знаниями проекта в Obsidian.

## 🛠 1. Авто-сохранение Сниппетов Кода
При написании удачного фрагмента кода или по запросу пользователя:
1. Оформить код с синтаксической подсветкой.
2. Добавить теги (например, `#python`, `#javascript`, `#helper`).
3. Сохранить файл в `Obsidian/Snippets/` с понятным заголовком.
4. Добавить ссылку в `Obsidian/Snippets/README Snippets.md`.

---

## 🏛 2. Автоматический ADR Logger (Фиксация Архитектурных Решений)
Когда в чате принимается важное техническое или архитектурное решение (смена фреймворка, базы данных, API или структуры ИД):
1. Сформировать файл в папке `Obsidian/ADR/` по формату `adr-YYYY-MM-DD-{название-фичи}.md`.
2. Заполнить секции:
   - **Контекст и Проблема:** Зачем потребовалось изменение.
   - **Принятое решение:** Что именно выбрали.
   - **Последствия и компромиссы:** Плюсы и минусы решения.
3. Проставить ссылку на проектную заметку в `Obsidian/Projects/` и в главную карту `Obsidian/База знаний.md`.

---

## 📌 3. Поддержание стандартов Frontmatter
При создании или обновлении заметок проектов гарантировать наличие YAML заголовка:
```yaml
---
title: "Название проекта"
status: "active" # active | completed | paused
category: "frontend" # frontend | mobile | automation | construction
stack: ["tech1", "tech2"]
code_path: "Путь к коду"
updated: YYYY-MM-DD
---
```
