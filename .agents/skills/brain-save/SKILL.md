# Навык: brain-save

Этот навык используется в конце разговора (или по прямому указанию пользователя) для сохранения результатов работы в базу знаний Obsidian.

## Процесс сохранения знаний

### Шаг 1: Анализ текущей сессии
Выделите ключевые элементы текущего диалога:
1. **Принятые решения:** Архитектурные выборы, выбор библиотек, алгоритмические подходы.
2. **Полученные инсайты:** Обнаруженные тонкости, баги, новые концепции, особенности конфигурации.
3. **Кодовые сниппеты:** Фрагменты кода, которые могут понадобиться в будущем.
4. **Задачи на будущее:** Шаги, оставшиеся нереализованными.

### Шаг 2: Проверка на дубликаты
Перед созданием новой заметки выполните поиск в Obsidian Vault с помощью инструмента `grep_search` по ключевым словам.
Если аналогичная заметка уже существует, не создавайте дубликат. Вместо этого используйте `replace_file_content` или `multi_replace_file_content` для дополнения существующей заметки, переведя ее статус в `status: growing`.

### Шаг 3: Создание файлов по шаблонам
Используйте шаблоны из папки `Obsidian/Templates/` для создания новых файлов:
- **Лонг-сессия / итоги разговора:** Сохраняйте в `Obsidian/Daily/YYYY-MM-DD-session-{project-name}.md` по шаблону `conversation.md`.
- **Новое архитектурное решение:** Сохраняйте в `Obsidian/ADR/adr-{short-name}.md` по шаблону `decision.md`.
- **Технический инсайт или паттерн:** Сохраняйте в `Obsidian/Projects/{project-name}/insights/` или корне Obsidian по шаблону `insight.md`.

При заполнении Frontmatter обязательно:
1. Заполнить текущую дату в `created` и `updated` (формат YYYY-MM-DD).
2. Заполнить краткое резюме `summary` (1-2 предложения).
3. Добавить теги по таксономии (например, `project/{project-name}`, `topic/{topic-name}`).

### Шаг 4: Связывание заметок (Cross-linking)
Найдите в базе знаний связанные заметки и добавьте ссылки на них:
- В поле `related` в формате `- "[[Имя заметки]]"`.
- В тексте заметки с использованием вики-ссылок `[[Имя заметки]]`.
- Обновите связанные заметки, добавив в них ссылку на вновь созданную.
