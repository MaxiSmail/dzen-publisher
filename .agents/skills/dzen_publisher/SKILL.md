# Dzen AI Publisher Skill (Автономный ИИ-Директор канала)

## Назначение
Автоматический сбор аналитики, генерация адаптивных ИИ-статей (мастер-классы, гайды, новости ИИ), создание 3D-обложек, человекоподобная публикация на Яндекс.Дзен через Playwright и отправка отчетов в Telegram. Поддерживает как локальный запуск, так и круглосуточную автономию через GitHub Actions.

## Ключевые параметры и цели
* **Ниша канала:** Искусственный Интеллект, Нейросети, ChatGPT, Claude, Midjourney, Промптинг, ИИ-новости.
* **Главная цель:** 30 часов (1800 минут) просмотров от ПОДПИСЧИКОВ за 30 дней для монетизации. Каждый пост содержит призыв к подписке (CTA).
* **Контекст текущего года:** СТРОГО **2026 ГОД**. Реализована двойная защита: явная системная инструкция Gemini + автоматическая код-фильтрация (замена "2025" на "2026").
* **Имитация человека (Anti-Bot):**
  * Поабзацная печать с паузами 10–35 мс на символ и паузами на знаках препинания.
  * Выделение подзаголовков H2 через `Control+B` для прописных букв.
  * Вставка 3D-обложки через буфер обмена (`Clipboard API` + `Control+V`).
  * Принудительное удаление обучающих оверлеев Дзена из DOM (`.ReactModalPortal, .ReactModal__Overlay`).
  * Клики по элементам в режиме `force=True`.
* **Облачный запуск (GitHub Actions):**
  * Репозиторий: `https://github.com/MaxiSmail/dzen-publisher`
  * Запуск каждый день в **13:00 МСК** (`0 10 * * *`) + случайная задержка 2–35 минут.
  * Мгновенный запуск по кнопке `workflow_dispatch`.
  * Секреты GitHub Actions: `GEMINI_API_KEY`, `DZEN_SESSION_STATE`, `TELEGRAM_BOT_TOKEN`, `TELEGRAM_CHAT_ID`.
  * Telegram-бот присылает фото обложки, заголовок, теги и статус сразу после выхода статьи.

## Структура файлов скрипта
* `config.py` — настройки, темы ИИ, ключи, системный промпт 2026 года.
* `agent_brain.py` — генератор адаптивных статей с привязкой к 2026 году и аналитике.
* `image_generator.py` — генерация 3D-обложек без текста.
* `publisher.py` — Playwright эмуляция печати, чистка DOM-оверлеев и вставка картинок.
* `analytics.py` — парсинг `/publications-stat` и `/money`, вычисление 30-часовой цели.
* `telegram_notifier.py` — отправка отчетов в Telegram с картинкой.
* `login_helper.py` — интерактивная авторизация и сохранение постоянного профиля браузера.
* `export_session.py` — экспорт сессии браузера в Base64 для `DZEN_SESSION_STATE`.
* `main.py` — оркестратор всех этапов.
* `.github/workflows/dzen_publisher.yml` — планировщик GitHub Actions.

## Порядок работы агента
1. **Проверка конфигурации:** убедиться в наличии ключей в `scripts/.env` (`GEMINI_API_KEY`, `TELEGRAM_BOT_TOKEN`, `TELEGRAM_CHAT_ID`).
2. **Авторизация в Дзене:**
   - Для локальной публикации: запустить `scripts/login.bat` (или `login_helper.py`) и авторизоваться в студии. Профиль сохраняется в `.chrome_profile`.
   - Для облачной публикации: выполнить `python scripts/export_session.py` и добавить полученную строку в секреты репозитория GitHub `DZEN_SESSION_STATE`.
3. **Запуск генерации и публикации:**
   - Локально: запустить `scripts/run_dzen_agent.bat` (или `publish.bat`, либо `python scripts/main.py`).
   - Скрипт последовательно: собирает аналитику -> формирует статью -> генерирует обложку -> эмулирует печать в Дзен -> отправляет отчет в Telegram.
