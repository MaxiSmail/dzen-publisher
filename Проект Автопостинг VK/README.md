# 🤖 Автономный VK-автопостинг (ИИ + RSS)

Автоматическая система публикации экспертного ИИ-контента во ВКонтакте на базе **Google Gemini API**, **Pollinations AI (Flux)** и **GitHub Actions**.

## 🚀 Описание работы

Бот работает в двух ежедневных режимах:
1. **Утро (режим `--mode own_rss`):**
   * Мониторит RSS-ленты технологий (Habr, TechCrunch).
   * Пишет экспертную развернутую статью с пошаговыми инструкциями и готовыми промптами (форматирование промптов через отступы и символы `>>>` без HTML).
   * Генерирует сюжетную картинку под тему статьи и публикует её на стене сообщества.
2. **День (режим `--mode dzen_adaptation`):**
   * Получает RSS-ленту вашего Яндекс.Дзен канала.
   * Как только выходит новая статья на Дзене (около 13:00-13:30 МСК), бот через 10-15 минут забирает её, очищает от HTML, адаптирует структуру под ВК, генерирует новую сюжетную обложку и публикует.

---

## 🛠 Установка и настройка

1. Перенесите ключи доступа в файл `scripts/.env`:
   * `GEMINI_API_KEY` — API ключ Google Gemini.
   * `VK_ACCESS_TOKEN` — токен сообщества ВК (создается в настройках группы: *Управление -> Работа с API -> Ключи доступа* с правами `wall` и `photos`).
   * `VK_GROUP_ID` — числовой идентификатор вашего сообщества.

2. Запуск локального тестирования:
   * **Утренняя статья:**
     ```bash
     run.bat own_rss
     ```
   * **Дневная адаптация Дзена:**
     ```bash
     run.bat dzen_adaptation
     ```

## 🔐 Как получить VK_ACCESS_TOKEN
1. Зайдите в управление вашей группы ВК.
2. Перейдите в раздел **Работа с API** -> **Ключи доступа**.
3. Нажмите **Создать ключ** и выберите права:
   * Разрешить приложению доступ к управлению сообществом.
   * Разрешить приложению доступ к фотографиям сообщества.
   * Разрешить приложению доступ к записям на стене сообщества.
4. Подтвердите создание ключа и скопируйте его значение.
